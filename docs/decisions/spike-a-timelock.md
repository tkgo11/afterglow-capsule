# Spike A — timelock interoperability

Status: **BLOCKED — partial Linux evidence only**. Review date: 2026-10-05.
Canonical acceptance: SPEC.md §21 and §148. No production dependency is adopted.

  exact registry artifacts/checksums in `spikes/Cargo.lock`. Default RFC9380

- Official Go reference: `v1.2.1-0.20260923175943-3ea7fbb59e85`, commit
  `3ea7fbb59e85d00b0d9b6b2554e9652d5766811b`; committed Go module/sum files.
- Local Go compilation used a temporary external workspace replacement for
  `drand/v2 v2.1.2` pointing at its official GitHub tag, commit
  `9a1af8b9700bc542aa2abe378b666eec925bdc1f`. The proxy's module ZIP redirect
  was HTTP 403; normal proxy/checksum/TLS validation was preserved. This local
  replacement is disclosed and is not present in the committed module graph.

Licenses, upstreams and unreviewed security status are in
[dependencies](../dependencies.md). Pins and public historical fixture provenance

## Commands and observed results

```sh
python spikes/timelock/check_historical.py --rust spikes/target/debug/afterglow-spike-a --go /tmp/afterglow-spike-a-reference
python spikes/timelock/test_live_inputs.py
```

Nine interoperability/security tests and two pure live-input tests passed. Go
build, vet, module verification and package checks passed with the disclosed local
workspace. The published Go ciphertext decrypts to its known public plaintext.
Fresh historical-round Go ciphertext decrypts in Rust, and fresh historical-round
Rust ciphertext decrypts in Go. Verified Quicknet and foreign-chain beacons at the
same round prove the wrong-chain test exercises BLS rejection, not merely a round
mismatch. Other rejection tests cover wrong pin, wrong round, invalid signature,
invalid randomness/key, truncation and ciphertext modifications. Failures never
create plaintext output. Synthetic payloads and already-public signatures are
test material; no private key or fake beacon was created.

Future ciphertext is generated by both libraries and cannot decrypt with an
already-public historical beacon. **This is not an after-round live future test.**
The ready [live runner](../../spikes/timelock/live_future.py) checks pinned metadata,
verifies latest, encrypts a future round, requires pre-round failure, then verifies
and decrypts the exact real target-round beacon in both directions.
